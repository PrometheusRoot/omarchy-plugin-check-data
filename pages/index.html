omarchy-plugin-check data

The signed store snapshot of omarchy-plugin-check: commit-bound safety verdicts for Omarchy plugins. Published daily; each snapshot is valid for 7 days. Human-readable reports: the site.

  • store.json + .sig (the CLI's contract)
  • store-manifest.json + .sig (store client bundle)
  • providers.json + .sig (provider registry)
  • api/v1/ (static API) · keys/allowed_signers

Verify (the key is also committed in the tool's spec/keys/allowed_signers):

ssh-keygen -Y verify -f allowed_signers -I omarchy-plugin-check \
  -n omarchy-plugin-check-snapshot -s store.json.sig < store.json
